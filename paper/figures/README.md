# Paper figures: provenance (final pass, item 19)

Every figure is rendered **from the committed benchmark artifacts only**
(no experiment is re-run, so the paper and the repository cannot drift
apart).  All five are regenerated by one command:

```bash
python paper/figures/generate_figures.py
```

| figure | content | committed data source |
|---|---|---|
| `fig1.{png,pdf}` | 24-complex redocking: best-pose RMSD per complex (green = within 2.0 Å, orange = above), 2.0 Å convention line, Wilson 95% CI in the title | `benchmarks/redocking/results/redocking_results.csv` + `summary_stats.json` |
| `fig2.{png,pdf}` | RMSD distribution histogram (n=24), mean/median/2.0 Å lines, success rate with Wilson CI | same |
| `fig3.{png,pdf}` | DockFlow vs MGLTools 1.5.7 best-pose RMSD scatter (21 MGL-completed complexes; y=x line; shared-denominator success counts in the title; 3 MGL crashes excluded) | `benchmarks/mgltools_comparison/results/comparison.csv` + `comparison_stats.json` |
| `fig4.{png,pdf}` | DUD-E hivpr ROC curve (re-plotted from the per-ligand committed scores; random diagonal) | `benchmarks/enrichment/results/hivpr/enrichment_results.csv` + `enrichment_metrics.json` |
| `fig5.{png,pdf}` | 3-target DUD-E enrichment summary table (hivpr / aa2ar / parp1) | `benchmarks/enrichment/results/{hivpr,aa2ar,parp1}/enrichment_metrics.json` |

All numbers cited in a manuscript should be cross-checked against
`benchmarks/redocking/results/summary.md`,
`benchmarks/mgltools_comparison/results/summary.md`,
`benchmarks/enrichment/results/summary.md` and
`docs/SCIENTIFIC_VALIDATION.md` (the single citable summary) - the
figures are visualisations OF those files, not a separate source of
truth.
